INSSAT TRAVEL SERVICE - نسخة إدارة العروض المحلية

المحتويات:
- index.html: الصفحة الرئيسية مع زر «إضافة عرض» ولوحة إضافة/تعديل/حذف.
- assets/logo-original.png: الشعار الأصلي.
- about-legacy.html: صفحة المعلومات القديمة المحفوظة.

طريقة الاستخدام:
1) ارفع محتويات هذا المجلد إلى مستودع GitHub Pages مع الحفاظ على مجلد assets.
2) اضغط «إضافة عرض» أعلى الصفحة.
3) كلمة المرور الافتراضية: Inssat@2026
4) غيّر كلمة المرور قبل النشر بتعديل ADMIN_PASSWORD داخل index.html.
5) أضف عنوان العرض والسعر والتاريخ والتفاصيل والصورة ثم «حفظ ونشر العرض».

تنبيه مهم:
هذا حل بسيط يعمل داخل المتصفح فقط. كلمة المرور موجودة في كود الصفحة ويمكن استخراجها، لذلك ليست حماية أمنية حقيقية.
العروض والصور تحفظ في localStorage على نفس المتصفح والجهاز فقط؛ لن تنتقل تلقائياً إلى أجهزة الموظفين أو إلى متصفحات الزبائن. كما أن حذف بيانات المتصفح قد يحذف العروض. لا تضع معلومات سرية أو بيانات زبائن هنا.
للنشر المشترك بين جميع الزوار والموظفين أو للحماية الحقيقية يلزم خادم/قاعدة بيانات ومصادقة خارجية.
